## One gallery, several television platforms

Museum at Home ships the same rights-checked, offline-first gallery to LG
webOS, Android TV / Google TV, Amazon Fire TV, Samsung Tizen and modern TV web
browsers. The shared TV-first interface keeps remote control, favorites,
collections and bilingual artwork stories consistent everywhere.

| Platform | Package | Status |
|---|---|---|
| LG webOS 3+ | `.ipk` in 1080p and 720p profiles | Fully supported |
| Android TV / Google TV | `.apk` | Fully supported |
| Amazon Fire TV | Android `.apk` | Supported for sideload testing |
| Samsung Smart TV / Tizen | Tizen web project | Ready for certificate signing |
| Modern television browser | PWA / static web build | Supported where browser APIs allow |
| Apple TV / Roku / VIDAA | Native port required | Roadmap |

## Highlights

- 55 commercially cleared artworks with local offline reproductions;
- Russian and world collections, favorites, genres and periods;
- detailed Russian and English stories;
- calm crossfades and optional gentle motion;
- UI that auto-hides for an uninterrupted ambient display;
- reliable D-pad, Magic Remote, Samsung Remote and Android Back handling;
- automated rights audit, ES5 compatibility tests and multi-platform CI.
